#+title: Readme Osc Data

* OscData easy introduction

The easiest way to load a number of OscData files from a folder, and then make a gui for them is to evaluate the statement:

#+begin_src sclang
OscData.loadPaths;
#+end_src

When run for the first time, this will open a FileDialog.  Select the folder that contains the OscData files.  *NOTE: This folder should not contain any scd files other than osc data files*.  OscData will save the path that you selected under =Platform.userAppSupportDirectory +/+ "Paths/"= with filename "oscdata.scd".

The next time you run =OscData.loadPaths;=, it will open the same folder.
If you want to open a different folder, then either erase the oscdata.scd file, or give a different name.  For example:


#+begin_src sclang
OscData loadPaths: \myOscSession_01;
#+end_src
