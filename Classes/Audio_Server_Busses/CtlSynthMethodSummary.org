#+title: Ctl Synth Method Summary

Summary of methods for mapping/unmapping controls to Synth.
Source file: CtlSynth.sc

The present serves as guide for use, for writing help files, and for adding the same methods to NodeTemplate / FunctionNodeTemplate.

* Summary of methods grouped by action type:

** rc, remap : restore (repeat) map to running control synth

** remapAll : remap all controls found in VarHolder

This serves to inherit the previous maps when starting (or restarting) a new synth in a NodeTemplate.

** c, ctl : add control synths for multiple key-function pairs

** add1Ctl : add control synth for a key-function pair

** c_, u, unmap : unmap each key in an array of arguments

See unmap1

control synths by setting the target synth's args bus value. Unmaps

** unmap1 unmap the control of the target synth by setting to the current value of the control bus

** cs, getCtlSynth get the control synth for a control name

** getCtl get the MapBus instance for a control name

** removeCtl remove the MapBus instance for a control name.
Do not do anything else.
Unmap must be done separately with c_, u, unmap or unmap1 above.

** cc_, stopCtl stop the synth of control at control name.

** freeCtls: stop all controls and free their buses
